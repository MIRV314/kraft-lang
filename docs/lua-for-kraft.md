# Lua за 10 минут — чтобы читать сгенерированный код

Kraft компилируется в Lua. Читать его проще, чем кажется: там всего
несколько конструкций. Этого файла достаточно, чтобы понимать `--emit-lua`.

## 1. Переменные

```lua
local x = 5        -- локальная переменная
x = x + 1          -- присваивание
```

`local` — «объявить здесь». В сгенерированном коде имена переменных
заменены на `v_1`, `v_2`, … в порядке объявления (кириллица в Lua
недопустима).

## 2. Числа, строки, булевы

```lua
local n = 3.5
local s = "привет"
local b = true
local nothing = nil
```

В Lua один числовой тип — как `flint`. Строки — байтовые.

## 3. Если и циклы

```lua
if x > 0 then
  ...
elseif x < 0 then
  ...
else
  ...
end

while x < 10 do
  x = x + 1
end

for i = 0, 4 do          -- 0,1,2,3,4
  ...
end
```

## 4. Таблицы — это и список, и словарь

```lua
local xs = {10, 20, 30}          -- индексы с 1
local d = { name = "Kraft" }     -- по ключу
print(xs[1])                     -- 10
print(d.name)                    -- Kraft
```

**Важно:** индексы в Lua начинаются с **1**, а в Kraft — с 0. Кодоген
сам прибавляет единицу; в сгенерированном коде ты увидишь `xs[i + 1]`.

## 5. Функции

```lua
local function add(a, b)
  return a + b
end
```

Функции — значения, их можно передавать.

## 6. Строки

```lua
local s = "a" .. "b"       -- склейка
local n = #s               -- длина в байтах
local up = s:upper()       -- метод через двоеточие
print(string.format("%d", 42))
```

В Kraft склейки нет — вместо неё `{}`-интерполяция, которая превращается
в `..` в сгенерированном коде.

## 7. nil и false

Ложь в Lua — только `nil` и `false`. Ноль и пустая строка истинны.
В Kraft ложь — `NONE` и `FALSE`, поэтому `NONE` — это отдельная таблица
`krt.NONE`, а не `nil`.

## 8. Ошибки

```lua
local ok, err = pcall(function()
  error("что-то сломалось")
end)
```

`pcall` ловит ошибку. Так `krt.run` печатает ошибки Kraft вместо Lua-
трейсбеков.

## 9. Метатаблицы (одна строка)

```lua
setmetatable(t, mt)
```

Это способ повесить на таблицу «тип». Так `krt.list` и `krt.dict`
отличаются друг от друга, хотя обе — таблицы.

## 10. Как выглядит программа Kraft

```kraft
str name = "Kraft"
show(привет, {name}!)
```

превращается примерно в:

```lua
local v_1 = "Kraft"
krt.show("привет, " .. krt.tostr(v_1) .. "!")
```

Всё остальное — детали. Если понимаешь эти десять пунктов, понимаешь
вывод `--emit-lua`.
