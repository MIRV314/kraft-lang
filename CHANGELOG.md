# История версий

## v0.2.0

Новая модель ядра в `xkraft` включена по умолчанию — без директив, режимов
и переключателей.

- Верхний уровень только объявляет: переприсвоение глобальной разрешено
  непосредственно в `func`, `for`, `while`; `if`/`elif`/`else` зоной
  изменений не являются (`TOPLEVEL_ERROR`).
- Глобальные без `ext`. Локальные, параметры и счётчики `for` не могут
  совпадать с именем глобальной (`REDECLARE_ERROR`).
- Блоки объявлений типа (`str:`, `flint:`, ...) и присваивание по индексу.
- Модели: `model`, `method`, `construct`, `self`, `init` — без наследования.
- Обработка ошибок: `try`, `trigger <КАТЕГОРИЯ>`, `ANY_ERROR`, `finally`.
  Объект `error` доступен в каждой ветке и доступен только для чтения;
  `finally` выполняется при любом исходе, включая неперехваченную ошибку
  и `return`.
- Имена капсом — жёсткие константы (`CONST_ERROR`); занятые имена включают
  методы встроенных типов (`NAME_ERROR`).
- `./kraft` остаётся замороженным эталоном v0.1. `xkraft.kraft` собирает
  сам себя; на совместимых тестах вывод побайтово совпадает с эталоном.
- `./install.sh` — ручная установка, `install-auto.sh` — автоматическая в
  одну команду с запросом прав; `--version` у обеих обёрток.

Не вошло в релиз: `froz`, `panic`, stdlib-prelude, модули, импорты и
установка на Windows.

Проверка: `make check` — 22/22 + 15/15 + 25/25 + 71/71.
