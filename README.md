# Kraft

Kraft — статически типизированный язык: один числовой тип, отступы вместо
фигурных скобок, интерполяция `{}` вместо склейки строк. Компилятор написан
на LuaJIT и компилирует `.kraft` в Lua, который сразу исполняет LuaJIT.
Никакого C, никакой сборки: одна команда — один запуск.

```sh
./kraft examples/hello.kraft
```

Структура репозитория:

- `kraft` — обёртка: компилирует `.kraft` во временный Lua и запускает
  `luajit`. Скрытый флаг `--emit-lua` печатает сгенерированный Lua.
- `src/` — компилятор: `lexer.lua`, `parser.lua`, `codegen.lua` и рантайм
  `krt.lua`, который вшивается в каждую программу.
- `examples/` — примеры.
- `tests/` — тесты (появятся в v0.1).
- `docs/` — `decisions.md` — источник истины по решениям; `rules.md` —
  старые заметки; `builtins.md` — полный список встроенных.

Цель: сначала базовый компилятор на LuaJIT, затем `xkraft` — компилятор,
написанный на самом Kraft и собирающий сам себя.

## Синтаксис: строки и отступы

Одна строка — один стейтмент. Блоки — **отступом** (4 пробела или таб,
только что-то одно). Без скобок, без `;`.

```kraft
str name = "Kraft"
flint version = 3
show(язык: {name} версия: {version})    # язык: Kraft версия: 3
```

Комментарии: `#` — до конца строки, `---` … `---` — многострочный.

## Типы

| Тип | Литерал | Примеры |
| --- | --- | --- |
| `str` | `"текст"`, `'текст'` | `"Kraft"`, `''` |
| `flint` | `42`, `-7`, `3.5` | один тип и для целых, и для дробных |
| `bool` | `TRUE`, `FALSE` | `TRUE` |
| `list` | `[1, 2, 3]` | `[]`, `[1, "a", [2]]` |
| `dict` | `{имя: значение}` | `{}`, `{режим: "быстрый"}` |
| `froz` | со списком в значении | `froz f = [1, 2]` — позже |
| модель | `Имя` + `init(...)` | `Counter` — позже |

`NONE` — обычное значение «пусто», его можно писать в коде и присваивать
переменной любого типа. Операции с `NONE` падают в рантайме: `NONE + 1` —
`TYPE_MISMATCH_ERROR`. Переприсвоил число — переменная снова нормальная.
`NONE` и `FALSE` — единственные «ложные» значения; `0`, `""`, `[]`, `{}`
истинны.

Печатаются значения так: строки на верхнем уровне без кавычек, числа как
есть (`42`, `3.5`), `TRUE`/`FALSE`, `NONE`, списки `[10, 20]`, словари
`{имя: "Kraft", возраст: 25}`. Внутри коллекций строки — в кавычках.

## Переменные и константы

```kraft
str name = "Kraft"      # объявление: тип обязателен
name = "Kraft 2"        # присваивание: тип не пишется
flint x = 1
x += 41                 # составное присваивание → 42
flint MAX = 100         # константа: всё имя заглавными
```

- Объявление только с значением: `flint x` — ошибка. Тип обязателен, вывода
  типа переменной нет. Повторное объявление — ошибка.
- Переменная видна **только после** объявления: чтение выше — ошибка.
- Присваивать можно сколько угодно, тип при этом не меняется.
- Составные присваивания: `+= -= *= /= //= %= **=` (только для чисел).
- Константа — имя без строчных латинских букв (`MAX`, `MAX_SIZE`, `X`).
  Присваивание константе — `CONST_ERROR`.

## Операторы

Арифметика (всё — тип `flint`), семантика Python:

| Операция | Что делает |
| --- | --- |
| `+ - *` | обычная арифметика |
| `/` | истинное деление: `7 / 2` — `3.5` |
| `//` | деление с округлением вниз: `-7 // 2` — `-4` |
| `%` | остаток, знак делителя: `-7 % 3` — `2` |
| `**` | степень, группировка вправо: `2 ** 3 ** 2` — `512` |
| `-` унарный | отрицание |

Деление на `0` и отрицательная степень с дробным показателем — `VALUE_ERROR`.

Сравнения: `== != < <= > >=`, результат `bool`. `==`/`!=` работают с любыми
типами (разные типы — `FALSE`, `NONE == NONE` — `TRUE`); `< <= > >=` — только
`flint`-`flint` и `str`-`str` (побайтово). Цепочки как в Python:
`0 <= x <= 10` — это `x >= 0 AND x <= 10`, средний операнд вычисляется один
раз. Логика: `AND`, `OR`, `NOT` (в скобках), результат `bool`, операнды
проверяются на истинность. Проверка типа: `n is flint`, `s is NONE`.

Склейка строк запрещена — `+` работает только с числами. Строки соединяются
только интерполяцией и `list.join(...)`.

## Строки и интерполяция

Строки в двойных кавычках или апострофах. Внутри — подстановки `{...}`.
Работает и в обычных строках, и в шаблонах `show`/`show_err`/`input`:

```kraft
str name = "Kraft"
flint version = 3
str msg = "привет, {name}!"

show({name})                              # значение переменной
show(версия {version}, следующая {version + 1})   # выражение
show(удвоенное: {double(21)})             # вызов функции
show({xs[0]})                             # элемент
show({user[имя]})                         # значение словаря
show(цена: $5)                            # $ — обычный символ
show(\{x\})                               # {x}
```

- Всё вне `{}` — текст: `show({x} + 1)` → `5 + 1`.
- `{` открывает подстановку, `}` закрывает; внутри — обычное выражение.
- `\{` и `\}` — литеральные скобки; `}` вне подстановки — ошибка.
- Пустая подстановка `{}` — `SYNTAX_ERROR`.
- Вложенные `{}` внутри выражения — литерал словаря: `show({ {a: 1} })`.
- В шаблонах `show(...)` скобки `(` и `)` — синтаксис вызова, поэтому в
  тексте шаблона они экранируются: `show(a \(b\))` → `a (b)`.

Экранирование: `\\` `\"` `\'` `\n` `\t` `\r` `\e` (`\e` — ESC), `\{`, `\}`.
Внутри `"..."` экранируется двойная кавычка, внутри `'...'` — одинарная;
«чужая» кавычка не экранируется.

## show и input

`show` печатает один текстовый шаблон (или пустую строку). Всё, что не `{}`,
является текстом; кавычки внутри шаблона не нужны.

```kraft
show()                             # пустая строка
show(привет)                       # привет
show(запятая, вот)                 # запятая, вот
show(элементы: {xs})               # элементы: [1, 2, 3]
```

`input` возвращает введённую строку, аргумент — подсказка: `input(как тебя
зовут? )`. `show_err` печатает в stderr. `show` и `show_err` возвращают
`NONE`. Программа может нести ввод с собой директивой `# stdin: текст` —
каждая такая строка читается раньше настоящего stdin.

## Условия

```kraft
flint age = 20
if age < 18:
    show(несовершеннолетний)
elif age < 65:
    show(взрослый)
else:
    show(пожилой)
```

`elif` сколько угодно, `else` — не больше одного и последний. Условие истинно,
если значение **не** `NONE` и **не** `FALSE`: ноль и пустая строка истинны.

## Циклы

```kraft
for i 5:               # 0, 1, 2, 3, 4 — форма «до N», правая граница не входит
for i 5..9:            # 5, 6, 7, 8 — 9 не входит
for i 10..0..-2:       # 10, 8, 6, 4, 2 — шаг задаёт направление

list numbers = [10, 20, 30]
for n in numbers:       # перебор элемента
    show({n})

flint i = 0
while i < 10:          # while, break, continue
    i += 1
    if i == 7:
        break
```

Переменная, объявленная внутри `if`/`for`/`while`, видна и после блока; если
блок не выполнялся — её значение `NONE`. **Исключение — переменная `for`**:
она живёт только внутри цикла, не перекрывает внешнее имя и не может быть
объявлена второй раз в той же функции. `break` и `continue` — только внутри
цикла. Шаг `0` в `for` — пустой цикл, не ошибка.

## Функции

```kraft
func summ(flint a, flint b) -> flint:
    return a + b

func greet(str who):
    show(Привет, {who})

show({summ(2, 3)})       # 5
```

- `func` только на верхнем уровне файла, вложенных функций нет.
- `return` — только внутри функции.
- Параметры типизированы (`тип имя`), аргументы позиционные.
- `-> тип` — **необязателен**: написал — обещаешь результат и проходишь
  проверку; не написал — компилятор выводит тип из `return` (все `return`
  должны давать один тип). Без результата `->` не пишется вовсе (никакого
  `-> NONE`). `return значение` — возврат, `return:` — пустой возврат.
  Рекурсия разрешена, но рекурсивной функции нужен явный `->`.
- **Функция видна после объявления:** вызвать её выше по файлу нельзя.
- Если тело может не выполнить `return` (например, `if` без `else`),
  результат считается «может быть NONE» и проверяется в рантайме.
- **Функция не видит переменные файла** — только свои аргументы и локальные.
  Всё нужное передаётся аргументами. Исключение — явный `glob` (позже):
  `glob total += n` (чтение: `glob total`).

## Зарезервированные имена

**Встроенное переименовать нельзя.** Ни функция, ни переменная (включая
константу, аргумент, поле), ни метод, ни имя модели не могут совпадать со
встроенным. Ошибка выдаётся при объявлении и перечисляет занятые имена.

```kraft
func len(flint n) -> flint:       # ошибка: имя занято глобальной функцией
func take():                      # ошибка: take — метод словаря
flint show = 5                    # ошибка: show — встроенная функция
```

Что считается встроенным:

| Категория | Примеры |
| --- | --- |
| Ключевые слова | `func`, `model`, `method`, `construct`, `if`, `elif`, `else`, `for`, `in`, `while`, `break`, `continue`, `return`, `is`, `AND`, `OR`, `NOT`, `glob`, `self`, `try`, `finally`, `trigger`, `panic`, `init`, `import_file`, `from_file`, `import_lib`, `from_lib` |
| Типы | `str`, `flint`, `bool`, `list`, `dict`, `froz` |
| Значения | `TRUE`, `FALSE`, `NONE` |
| Глобальные функции | `show`, `show_err`, `input`, `len`, `type`, `str`, `flint`, `up`, `low`, `title`, `abs`, `round`, `floor`, `ceil`, `sqrt`, `min`, `max`, `sum`, `avg`, `keys`, `values`, `upk`, `sort`, `reverse`, `clear`, `map`, `filter`, `reduce`, `read_file`, `write_file`, `file_exists`, `args`, `exit`, `time_ms`, `is_tty`, `system`, `assert`, `expect` |
| Методы по типам | list: `add`, `del`, `remove`, `replace`, `contains`, `count`, `index`, `join`; dict: `add`, `take`, `remove`, `contains`, `merge`; строка: `part`, `find`, `contains`, `preff`, `suff`, `trim`, `triml`, `trimr`, `replace`, `count` |

Имя модели тоже проверяется. По конвенции модели — `CapWords`, поэтому
практически ошибка возможна только для имени в нижнем регистре:
`model list:` — ошибка.

## Коллекции (кратко)

```kraft
list nums = [10, 20, 30]
nums.add(40)                  # в конец
nums.del(0)                   # удалить по индексу
show({nums})                  # [20, 30, 40]
show({nums.contains(20)})     # TRUE
show({nums.join(", ")})       # текст через разделитель

dict user = {имя: "Kraft", возраст: 25}   # ключ — всегда строка, порядок пар сохраняется
show({user[имя]})                          # Kraft — ключ без кавычек, как в литерале
show({user.take("возраст")})               # то же самое, форма take
user.add("рост", 180)
for k, v in user:                         # перебор ключей и значений
    show({k} = {v})

froz frozen = [1, 2, 3]        # позже: читать можно, менять нельзя
```

Ключ в скобках у словаря пишется как в литерале: `user[имя]` и
`user["имя"]` — одно и то же. Значение переменной-ключа читается через
`take(key)`.

`take` отсутствующего ключа — `NONE`, не ошибка. Списки, словари и модели
передаются **по ссылке**.

`list`/`dict` без параметра типа могут хранить разные типы; чтение из них
проверяется в рантайме. `list[flint]`/`dict[str|flint]` — полная статика.

Значение из такого чтения имеет внутренний тип «что угодно»: его можно
присвоить переменной любого типа или вернуть из функции — проверка будет
при использовании. Индекс, срез и `for-in` работают сразу
(`xs[0][1]`), а метод сначала привяжи к типу:

```kraft
list rows = [[1, 2], [3, 4]]
list row = rows[0]     # проверка, что это действительно список
row.add(5)
show({rows[0]})        # [1, 2, 5] — та же ссылка
```

## Срезы и индексы

Работают у строк и списков; правая граница не входит:

```kraft
s[0]          # один символ
s[0..5]       # символы 0..4
s[..5]        # левая граница открыта
s[7..]        # правая открыта
s[-6..]       # отрицательный индекс
xs[1..5..2]   # с шагом
```

Обратный диапазон (`xs[3..1]`) — пустой список, не ошибка. Шаг `0` в срезе и
индекс за пределами списка — `VALUE_ERROR`.

## Методы строк

Индексы и длины — в символах UTF-8, с нуля.

| Метод | Что делает |
| --- | --- |
| `s.part(a, b?)` | подстрока `a..b` (без `b` — до конца) |
| `s.find(sub)` | индекс первого вхождения или `NONE` |
| `s.contains(sub)` | `TRUE`, если подстрока есть |
| `s.preff(p)` | начинается с `p` |
| `s.suff(p)` | заканчивается на `p` |
| `s.trim()` / `s.triml()` / `s.trimr()` | убрать пробелы |
| `s.replace(old, new)` | заменить все вхождения |
| `s.count(sub)` | число неперекрывающихся вхождений |

```kraft
str s = "  Привет, мир  "
show({s.trim()})              # Привет, мир
show({s.find("мир")})         # 10
show({s.replace("мир", "Kraft")})
show({s.find("кот") is NONE}) # TRUE
```

## Методы коллекций

Списки и словари передаются по ссылке: `list ys = xs` не копирует, а
`ys.add(...)` меняет тот же список. `==` сравнивает ссылки.

| Метод списка | Что делает |
| --- | --- |
| `xs.add(v)` | добавить в конец |
| `xs.del(i)` | удалить по индексу (за границей — `VALUE_ERROR`) |
| `xs.remove(v)` | удалить первое вхождение, вернуть `bool` |
| `xs.replace(i, v)` | заменить элемент по индексу |
| `xs.contains(v)` / `xs.count(v)` | есть ли / сколько раз |
| `xs.index(v)` | индекс первого вхождения или `NONE` |
| `xs.join(sep)` | элементы через `str`, разделитель `str` |

| Метод словаря | Что делает |
| --- | --- |
| `d.add(k, v)` | добавить или заменить пару |
| `d.take(k)` | значение или `NONE` |
| `d.remove(k)` | удалить ключ, вернуть `bool` |
| `d.contains(k)` | есть ли ключ |
| `d.merge(other)` | добавить пары `other`, совпавшие ключи перезаписать |

```kraft
list xs = [1, 2, 3]
xs.add(4)                     # [1, 2, 3, 4]
xs.del(0)                     # [2, 3, 4]
show({xs.index(3)})           # 1
show({xs.join("-")})          # 2-3-4
show({xs.index(99) is NONE})  # TRUE

dict d = {a: 1}
d.add("b", 2)
show({d.take("b")})           # 2
show({d.take("нет")})         # NONE
d.merge({c: 3})               # {a: 1, b: 2, c: 3}
```

`for x in xs:` перебирает элементы списка, `for k, v in d:` — пары
словаря в порядке вставки.

## Встроенные функции

| Вызов | Что делает |
| --- | --- |
| `len(x)` | длина: `str` — символы UTF-8, `list` — элементы, `dict` — ключи |
| `type(x)` | имя типа текстом: `"str"`, `"flint"`, `"bool"`, `"list"`, `"dict"`, `"NONE"` |
| `str(x)` | текст значения, как при печати |
| `flint(x)` | число из числа, `bool` (1/0) или строки |
| `read_file(path)` | весь файл; нет файла — `FILE_ERROR` |
| `write_file(path, text)` | перезаписать файл целиком, `TRUE` |
| `file_exists(path)` | `bool` |
| `args()` | список строк: `[0]` — путь к исходнику, дальше аргументы |
| `exit(code)` | завершить программу с кодом |
| `time_ms()` | процессорное время в миллисекундах |
| `is_tty()` | `TRUE`, если stderr — терминал |

```kraft
show({type(42)}, {type("x")}, {type(NONE)})          # flint, str, NONE
show({len("Привет")}, {len([1, 2])}, {len({a: 1})})  # 6, 2, 1
show({flint("42") + 1})                              # 43
show({str([1, "два"])})                              # [1, "два"]
```

`flint("abc")` — `VALUE_ERROR`. Встроенные имена (`len`, `type`, `str`,
`flint`, `args`, ...) нельзя использовать как имена переменных, функций,
параметров и переменных цикла — `NAME_ERROR`.

## Ошибки

Каждая ошибка печатается так:

```
TYPE_ERROR: имя_файла:12
   12 | flint x = "текст"
                        ^ expected declaration of 'x': type flint, found str
```

Категория, файл и номер строки; строка кода; каретка `^` под местом
ошибки; пояснение рядом. Столбцы считаются в символах.

Пояснение — на английском, из двух частей: `expected X` (что ожидалось)
и `found Y` (что найдено). Когда stderr — терминал, категория печатается
красным, `expected X` жёлтым, `found Y` красным; при перенаправлении
вывод чистый, без escape-кодов.

Категории: `SYNTAX_ERROR`, `NAME_ERROR`, `REDECLARE_ERROR`, `CONST_ERROR`,
`TYPE_ERROR` (компиляция), `SCOPE_ERROR`, `ARGCOUNT_ERROR`, `VALUE_ERROR`,
`CONCATENATE_NOT_SUPPORT`, `FILE_ERROR`, `TYPE_MISMATCH_ERROR` (рантайм),
`PANIC_ERROR`, `RUNTIME_ERROR`, `GENERATE_ERROR`, `ASSERT_ERROR`,
`EXPECT_ERROR`.

Ошибки компиляции (тип, имя, арность) показываются до запуска; остальное
приходит из времени выполнения.

## В разработке

Слова ниже зарезервированы, но вне v0.1: компилятор отвечает
`v0 feature: <слово> (growth stage)` в позиции слова.

- **модели** — `model`, `method`, `construct`, `self`, `init`;
- **обработка ошибок** — `try`, `trigger`, `finally`, `panic`;
- **глобалы из функции** — `glob`;
- **замороженные коллекции** — `froz`;
- **файлы и библиотеки** — `import_file`, `from_file`, `import_lib`,
  `from_lib`;
- **тестирование** — `assert`, `expect`;
- **функции высшего порядка** — `map`, `filter`, `reduce`.

**Типизированные коллекции** — после базового компилятора:

```kraft
list[flint] nums = [1, 2, 3]            # только числа: строка в литерале — ошибка
dict[str|flint] cfg = {возраст: 25}     # ключ|значение, два типа через |
froz[flint] frozen = [1, 2]             # froz — тоже коллекция
list[list[str]] matrix = []             # вложенность
```

- Проверка содержимого: в литерале — уже при компиляции; при записи
  (`add`, `set`, `insert`) — в рантайме, с указанием типа.
- Срез сохраняет тип, как `froz` → `froz`.
- Только для коллекций: `list`, `dict`, `froz`.
